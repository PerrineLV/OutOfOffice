# Out of Office

Appli de rencontres qui exclut automatiquement les collègues et connaissances
professionnelles du catalogue de profils, sans jamais révéler pourquoi
quelqu'un n'apparaît pas.

Projet en cours de développement.

## Stack prévisionnelle
- JavaScript (Node.js)
- Express
- PostgreSQL + Prisma
- Socket.IO (chat temps réel)
- React
- Docker Compose (Postgres)
